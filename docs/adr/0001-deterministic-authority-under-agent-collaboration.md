# ADR-0001：Agent 协作下的确定性裁决权

- 状态：Accepted
- 日期：2026-10-04

## 背景

产品需要处理自然语言偏好、图像语义、异质库存和完整分配。用户希望突出 Multi-Agent 协作，但结构相关硬约束必须可复现、可测试和可审计。

## 决策

采用分层职责：

1. Agent 负责需求理解、证据整理、视觉软偏好、流程编排和解释；
2. Rule Engine 负责材料—Slot 硬规则三态判决；
3. Constraint Solver 负责完整分配、唯一使用和软目标优化；
4. 任何 Agent 产生的候选方案在展示、保存或导出前都要确定性复核；
5. 领域合同和规则引擎不依赖真实 LLM，能够作为工具输入、输出和独立测试边界。

Agent 是职责与控制边界，不代表每一步必须调用 LLM。固定校验优先使用程序；只有语言或视觉语义确有需要时才调用模型。

## 结果

- Multi-Agent 可以成为产品协作层，但不能形成多个模型投票决定安全的架构；
- 硬规则和求解结果能够在没有模型时独立测试；
- Agent 数量、调用次数和模型选择可以通过后续评测调整；
- 领域合同变化会影响 Adapter、Rule Engine、Solver、API 和 Agent Tools，必须保持向后可解释。
